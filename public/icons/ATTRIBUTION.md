`skills/` 8종은 game-icons.net(Lorc) SVG를 그대로 복사했다.
재배포 조건(CC BY 3.0, https://creativecommons.org/licenses/by/3.0/)에 따라 작가·링크를 밝힌다.

- 작가: Lorc (https://game-icons.net)
- 파일: `fire.svg`(fireball), `grass.svg`(vine-whip), `water.svg`(drop),
  `rock.svg`(rock), `wind.svg`(tornado),
  `buff.svg`(strong), `debuff.svg`(shouting)
- `basic.svg`: AF-2/3에서 자작 3선 타격 마크로 교체(17px에서 punch-blast가 흰 덩어리로 보이던 문제). CC BY 해당 없음.
- 원본: https://github.com/game-icons/icons (`lorc/*.svg`)
- 라이선스: CC BY 3.0

UI 아이콘(도망·거리·배틀)은 Lucide(ISC, https://lucide.dev) SVG path를
컴포넌트에 inline 복사했다(패키지 설치 없음). 해당 파일 상단 주석에 출처 표기.
